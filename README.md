# LLL Phone Utility Toolkit

Developed by LLL Inc.'s dev team — visit us at https://www.live-laugh-love.world

A free, privacy-first toolkit of 10 handy on-device tools, installable as a
PWA. Everything runs on-device — no account, no uploads.

**Live:** https://lll-phone-util.pages.dev/

## Tools

- **Scan Document** — capture and clean up document scans
- **OCR Image to Text** — extract text from an image
- **Voice to Text** — speech-to-text dictation
- **Text to Speech** — read text aloud
- **QR Scanner** / **QR Code Generator**
- **Barcode Scanner**
- **Camera Mirror** — use your camera as a mirror
- **Unit Converter**
- **Password Generator**

## Tech

- Plain HTML/CSS/JS, installable Progressive Web App (`manifest.json`, icons)
- Multi-language interface
